Estimated Time: ~1 hour

Steps:

Endpoint: /posts

Save: id, title, body to posts.csv

Read back with DictReader

Task 3: Real API + Analysis (Hard)
Estimated Time: 2–3 hours

Objective: Use the Open-Meteo weather API (free, no key needed) to fetch a 7-day weather forecast for Kathmandu. Save to CSV and find the hottest/coldest days.

Steps:

API: https://api.open-meteo.com/v1/forecast

Params: Kathmandu's latitude/longitude, daily=temperature_2m_max

Save: date + max_temp to weather.csv

Analyze: Find max/min temp and print which day they occurred.

Bonus: Save a summary to a .txt file.

Deliverable: weather.csv + analysis script
