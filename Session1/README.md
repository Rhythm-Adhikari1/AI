# Session1 Python Scripts

This folder contains a small collection of introductory Python scripts. Each file is documented with a module description and, where applicable, function docstrings.

## File Overview

### `words_in_file.py`
Reads a text file entered by the user and returns the total number of whitespace-separated words.

### `max_min.py`
Defines helper functions to find the largest and smallest values in a numeric list, then demonstrates them with an example list.

### `multiplication.py`
Prompts the user for a number and prints its multiplication table from 1 to 10.

### `results.py`
Prompts the user for marks and assigns a grade using a fixed grading scale.

## Notes

- These scripts are intended for direct execution.
- Some files accept console input, so they should be run in an interactive environment.
- The examples are deliberately simple and suitable for beginner-level practice.
